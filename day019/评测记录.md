# Day019 评测记录

## 评分规则

忠实于原文记 1 分；出现事实错误或遗漏关键限制记 0 分。

## 两版 Prompt

- A：请概括用户提供的文本。只返回 JSON，包含 summary（字符串）和 keywords（字符串列表）。
- B：请概括用户提供的文本。只返回 JSON，包含 summary（字符串）和 keywords（字符串列表）。如果原文包含权限或次数限制，保留权限要求，以及次数限制的周期、上限等含义；原文没有的信息，请不要擅自添加。

## 样本 S01：账号导出权限

- 原文：试用账号不能导出报表。付费账号每天最多导出 3 次。
- 人工错误摘要：所有账号每天都可以导出3次报表。
- 评分：0 分。
- 失败原因：原文禁止试用账号导出，仅允许付费账号每天最多导出 3 次；错误摘要把导出权限扩大到了所有账号。
- 来源：教练提供的人工失败样本，非模型实际运行结果。本条完整记录由助手应本人要求代写示例。
- 关键边界：摘要必须保留账号权限区别，以及“每天最多 3 次”的限制，不能扩大权限。

## 样本 S02：上线信息尚未确定

- 原文：报表导出功能计划下周上线，目前尚未开放。具体上线日期和每日导出次数尚未确定。

## 样本 S03：报销撤回条件

- 原文：员工可以撤回尚未审批的报销申请。申请一旦审批通过，员工不能自行撤回，必须联系财务处理。撤回申请不会删除历史记录。

## 样本 S04：工单统计范围

- 原文：本周共收到120张工单，其中90张已解决，30张仍在处理中。已解决工单的平均处理时间为2小时，该平均值不包含仍在处理中的工单。

## 样本 S05：新旧规则与审批限制

- 原文：旧版说明曾写所有员工都能导出客户名单，该说明现已作废。现行规则是：仅管理员可以导出，每周最多2次；普通员工只能查看，不能导出。管理员导出前仍需完成审批，紧急情况也不能跳过审批。
